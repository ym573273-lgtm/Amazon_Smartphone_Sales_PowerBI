# Amazon Smartphone Sales Analytics (Power BI)

Final project: a Power BI dashboard analyzing Amazon smartphone search data.

## Files
- .pbix: Power BI report
- phone_search.csv: dataset

## What was done
- Data cleaning in Power Query: fixed data types, handled nulls, removed duplicates.
- DAX measures: average price, average rating, total sales volume, number of offers, best sellers count, Amazon Choice count, price difference, % climate friendly.
- Dashboard with bar charts and pie charts showing sales, prices, ratings, Prime, and climate-friendly share.
